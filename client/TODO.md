## 与 A/B 的交接

- [ ] 与 A 冻结 32 字节头、binary32、UUID 原始 16 字节、错误码和完整测试向量。
- [ ] A 返回错误回复时仍回显请求身份和请求的模式；C 能收到模式不匹配错误。
- [ ] B 的监控确认返回 `remainingMillis`，C 不把它当作秒或原始监控时长。
- [ ] 注册确认之前到达的 callback 能暂存；callback 的 ID 是监控注册 ID。
- [ ] 与 A 固定故障选择器 `UUID:requestId`；两个客户端不共用 session。
- [ ] 每人维护自己模块的测试与报告，C 负责汇总，不代替 A/B 验证业务与语义。

## 后续必须验证的边界

- [ ] 中文字符串按 UTF-8 字节数编码；NaN/Infinity/超出 binary32 范围的输入被拒绝。
- [ ] 收到无关报文或连续 callback 不会无限延长当前请求的超时。
- [ ] 客户端重启使用新 session；不同客户端相同 requestId 互不混淆。
- [ ] 业务错误不自动重试；最终超时不自动换 ID 再次订座/加价。
- [ ] 监控重放确认不重新等待完整时长；剩余时间 0 立即结束。
- [ ] 菜单退出和异常路径能关闭 socket。
