- [x] 业务错误（含模式错误）一次回复就结束。
- [x] 首次丢请求消耗尝试；全请求丢失没有 send；全回复丢失不会生成新写请求。
- [x] 迟到旧回复不能确认下一次调用；requestId 上限不会回绕。
- [x] 新实例产生不同 session；固定 session 选择器校验。
