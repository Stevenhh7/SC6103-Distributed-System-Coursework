## 接口交接检查

- [ ] A/B 使用同一个监控实例；RequestContext.peer 来自实际数据报。
- [ ] B 的正常业务错误通过 Response 返回；失败不产生 callback。
- [ ] 监控原登记过期/被替换后，AMO 重放仍确认原操作，但剩余时间为 0。
- [ ] A 缓存成功/失败回复后才发送或丢弃；数组不能引用下次接收会覆盖的 buffer。
- [ ] callback 的 session/requestId 属于监控客户端；每个接收者独立发送。
- [ ] 回复发送失败不回滚业务，也不阻止其他 callback；发送前复查登记有效期。
- [ ] 空闲时接收超时能触发清理；不得让登记只在下次订座时才删除。
- [ ] 同请求键的不同字节/源端点被拒绝，历史不被覆盖。
- [ ] requestId 上限、updateSequence 上限和报文长度均不回绕/静默截断。
